# Skill Validator

> Mantenedores do kit / CI. Humano final: `./jojo` + IA.

```bash
./jojo sync
# ou
cd kit && npm run validate:skills
```

## Layout

```
kit/docs/skills/<id>/
  SKILL.md
  references/   # opcional L3
```

- `name` = id da pasta (lowercase-hyphen)  
- `description` = o quê + quando (gatilho L1)  
- Seções **Quando usar** / **Quando NÃO usar**
