# Skill: A11y

## Quando usar

- Qualquer UI nova ou alterada  
- Fase UX e validação Dev/QA  

## Quando NÃO usar

- Sem superfície humana (N/A de UI)  

## Checklist mínimo

- [ ] Teclado / ordem de foco  
- [ ] Foco visível  
- [ ] Labels em controles  
- [ ] Contraste  
- [ ] `alt` útil  
- [ ] Status não só por cor  

## Critérios de saída

- [ ] Checklist ok ou débitos com OK humano
