# Examples

Exemplos **completos de app com UI** (ex.: todo-app golden) ficam **de fora por enquanto** — o foco atual é o kit de processo/CLI.

O que usar hoje para aprender o fluxo:

1. `./devkit init /tmp/meu-app && cd /tmp/meu-app`
2. `./devkit propose --title "…" --persona "…" --want "…" --so-that "…"`
3. Seguir PM → UX → Architect no chat
4. `./devkit doctor` / `./devkit log` para inspeção

Quando formos acrescentar um exemplo com UI de verdade, ele viverá aqui como projeto mínimo versionado (stack explícita + `design-premises` preenchido).
